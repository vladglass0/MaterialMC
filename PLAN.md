# План миграции Linux GUI

## Цель и границы

Довести MaterialMC на Linux до рабочего React + TypeScript интерфейса в системном WebView, сохранив существующую логику C++.

- Не переносить FTB (включая legacy/App), Technic и ATLauncher.
- Не реализовывать Windows/macOS WebView в рамках этой работы.
- Скины и плащи отложены; управление аккаунтами остаётся.
- Qt GUI сохраняется как запасной вариант до проверенного паритета нужных сценариев.
- Коммиты, пуши и изменение Git-истории — только по явному разрешению пользователя.

## Текущая отправная точка

Реализованы RPC/WebView-инфраструктура, расширенное управление инстансами, редактор компонентов и инфраструктура переводов/вопросов backend → React. Добавлены поиск, версии и установка Modrinth/CurseForge, импорт архива через нативный выбор файла и импорт по HTTP(S) URL.

Проверены поиск и версии обоих провайдеров и установка Modrinth. Исправлена ошибка отложенного сохранения профиля после переноса временного инстанса; итоговый `mmc-pack.json` проверен. Это не подтверждает запуск Minecraft. Установка CurseForge и полный сценарий импорта ещё требуют проверки. Текущий локальный `build/` настроен с `BUILD_TESTING=OFF`.

## 1. Завершить модпаки и импорт — ближайший этап

- [ ] Проверить реальную установку CurseForge.
- [ ] Проверить импорт ZIP/`.mrpack` из файла и URL.
- [ ] Перенести обновление существующих сборок: API и вкладку Managed Pack.
- [ ] Подключить URL-схемы и нативный drag & drop без передачи произвольных локальных путей от страницы.
- [ ] Проверить отсутствие исключённых провайдеров в React-интерфейсе; существующий backend/Qt-код не удалять автоматически.

Критерий завершения: сборку можно установить, обновить и запустить из React без обращения к Qt GUI, кроме разрешённых нативных файловых диалогов и подтверждений безопасности.
